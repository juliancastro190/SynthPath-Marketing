# faceless-youtube

Operating runbook for the faceless Reddit-horror-stories YouTube channel (ElevenLabs narration, script-based FFmpeg/Remotion assembly, AI-generated thumbnails). The full runbook lives in the vault at [`Marketing/faceless-youtube.md`](../../../Marketing/faceless-youtube.md) — read it before doing any work on this channel: story sourcing/rights, script adaptation, voice generation, visual assembly, thumbnails, titles, upload cadence, and what to measure.

## The one rule

Never produce a video-pipeline output (script, thumbnail prompt, title, upload plan) cold. Read `Marketing/faceless-youtube.md` first, every time — it has the concrete stack (ElevenLabs voice ID conventions, the FFmpeg/Remotion assembly shape, the thumbnail style guide) and the retention/CTR thresholds that turn the channel's numbers into decisions.
